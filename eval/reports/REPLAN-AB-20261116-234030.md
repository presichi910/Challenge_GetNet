## How to read the differences

A difference in a row where no replan action fired is not evidence about the replan: no replan action ran in that row. This report does not establish its cause. Candidates and baselines also differ in run date, commit and judge session, and some rows depend on tool data or web search results that change with the date.

With 3 repetitions with the replan on against 5 base repetitions and a judge that is not deterministic, this report makes no statistical inference: it lists, row by row, what each repetition did.
